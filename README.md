# Thư viện ảnh tương tác

## Chạy bằng VS Code
1. Giải nén ZIP và mở thư mục `interactive-photo-gallery` trong VS Code.
2. Nhấp phải `index.html` rồi chọn **Open with Live Server**.
3. Ảnh dùng URL Unsplash nên cần kết nối Internet.

## Đã bao gồm
- Sáu ảnh có `alt`.
- Sự kiện chuột `onmouseover`, `onmouseleave`.
- Sự kiện bàn phím `onfocus`, `onblur`.
- `onload="addTabFocus()"`, vòng lặp `for` thêm `tabindex="0"`.
- `console.log()` để kiểm tra sự kiện.
